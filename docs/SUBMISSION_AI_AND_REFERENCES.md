# Submission — AI disclosure and references (game runtime only)

Scope: the **playable game** — level data, rover simulation, survey kit, HUD, scoring, mission elements, audio and interface. The analysis lenses (THEMIS heat, solar/shadow and radiation *layers*), the Research sandbox and the offline preprocessing pipeline are outside this scope.

Prepared 2026-11-13. Everything below was checked against the repository, the PDS labels in `data/raw/`, and the shipped assets in `public/data/`.

---

## 1. AI tools used

| Tool | Access / version | What it was used for | Data it worked on |
| :--- | :--- | :--- | :--- |
| **Google Antigravity** | Agentic IDE (version not recorded) | Primary coding agent for the gameplay runtime: scaffolding, refactoring and debugging of rover movement/physics, dust, HUD, survey kit, scoring, state machine and UI; drafting of level and mission-element JSON; tuning constants; player-facing copy. | Gameplay source (`src/game/**`, `src/ui/**`, `index.html`, `src/style.css`); level data (`src/game/levels/level01.json`, `level01_elements.json`); read-only reads of `public/data/*` rasters to derive placement candidates. |
| **OpenCode** | CLI coding agent, model *DeepSeek V4.1 Flash Free* | Repository audit only, during this submission's preparation: verified README/technical claims against code and PDS labels, re-ran the elevation check, and drafted `README.proposed.md` and this disclosure. No gameplay code or game data was written or changed. | Read-only access to `README.md`, `docs/`, `src/`, `public/data/`, `data/raw/`; executed `scripts/check_route_elev.py` and, in an isolated copy under `/tmp`, `scripts/generate_level01.mjs`. |

**How AI was used.** Both tools assisted with software engineering, dataset integration, UI implementation and descriptive copy. Numeric terrain, slope, route and traverse values were produced by scripts from the PDS products listed below — no elevation, slope, coordinate, sol or spectral value was generated by an AI model. Descriptive text written by AI (level briefing, hazard/resource descriptions, tutorial and HUD copy) is game content and is tagged `game` / `MISSION RULE` in the app, never `MEASURED` or `DERIVED`.

**Not AI-generated.** The rover model is procedural geometry in `src/game/rover/roverModel.js` (no AI-generated or third-party 3D assets). Screenshots were captured from the running app with Playwright.

## 2. References — datasets

| Dataset | Product ID / file | Archive | Used in the game for |
| :--- | :--- | :--- | :--- |
| Gale Crater 1 m DEM | `MSL_Gale_DEM_Mosaic_1m_v3.tif` | [USGS Astrogeology Science Center](https://astrogeology.usgs.gov/search/map/mars_mgs_ctx_hirise_gale_crater_dem_1m) · [PDS Geosciences](https://pds-geosciences.wustl.edu/) | Terrain height for the mesh and rover ground sampling; 5 m-baseline slope field driving grade resistance, slope warnings and survey scans |
| HiRISE colour mosaic | `MSL_Gale_HiRISE-LRGB_78quads_sharp_cog.tif` | [HiRISE Operations Center](https://hirise.lpl.arizona.edu/) · [UA HiRISE](https://www.uahirise.org/) | Base 2 m/px surface texture under the rover and gameplay elements |
| MSL localization RDR ("Places") | `MSL-M-ROVER-6-RDR-PLACES-V1.0`, file `localized_interp.csv` | [PDS Geosciences — MSL](https://pds-geosciences.wustl.edu/missions/msl/) | Reference traverse line, level start point, science-target coordinates, debrief comparison |
| CRISM map-projected mineral products | `T0902_MRRHYD_05S138_0327_4`, `T0902_MRRPHY_05S138_0327_4` (`MRO-M-CRISM-5-RDR-MULTISPECTRAL-V1.0`) | [PDS Geosciences — CRISM multispectral RDR](https://pds-geosciences.wustl.edu/mro/mro-m-crism-5-rdr-multispectral-v1/) | Placement of two clay/sulfate science targets; the science-weighted route strategy |
| MSL RAD dosimetry | `MSL-M-RAD-3-RDR-V1.0` | [PDS Planetary Plasma Interactions](https://pds-ppi.igpp.ucla.edu/) | Literature baseline for the simulated HUD dose rate: the app uses a conservative 20 µSv/h constant against the ~0.64 mSv/day (~27 µSv/h) surface dose equivalent reported by Hassler et al. (2014); the RDR file is not ingested at runtime |

Also used for sol/target context (labels pending sol-level verification): [Curiosity mission updates](https://science.nasa.gov/mission/msl-curiosity/science-updates/) and the [Curiosity location map](https://science.nasa.gov/mission/msl-curiosity/location-map/).

*Out of scope:* the THEMIS daytime-IR mosaic (`THEMIS_DayIR_ControlledMosaic_Aeolis_30S135E_100mpp.tif`, [THEMIS/ASU](https://themis.asu.edu/)) feeds the Heat lens only and is not used by the game runtime.
